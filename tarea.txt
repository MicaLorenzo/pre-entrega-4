Pre-Entrega 4: Uso e interacción con Arrays
¡Felicidades por llegar al final del módulo de Arrays! Hasta ahora, has aprendido a declarar variables, controlar el flujo con ciclos y modularizar tu lógica con funciones.Ahora sumamos una pieza fundamental: los Arrays, que nos permiten agrupar datos relacionados en una sola estructura.

¿Qué estamos construyendo?
En entregas anteriores, trabajamos en la lógica de decisión y en funciones reutilizables. Ahora, es momento de que esa lógica tenga datos sobre los cuales actuar.

Temas clave a validar
1. Manipulación de extremos
Debes ser capaz de gestionar una lista dinámica. No siempre agregamos elementos al final; a veces el orden de entrada importa.

push / pop: Para trabajar con el final de la lista.
unshift / shift: Para gestionar prioridades al inicio de la lista.
2. Acceso y Modificación por Índice
El array no es una caja negra. Cada elemento tiene una "dirección" (índice). Debes poder entrar a una posición específica (ej. miArray[2]) y cambiar su valor sin afectar al resto de la colección.

3. Iteración Eficiente
Recorrer la lista es la operación más común. Usaremos:

for...of: La forma moderna y legible de leer cada elemento.
4. Búsqueda y Validación
Antes de operar con un dato, debemos saber si existe. Algunos métodos útiles pueden ser:

includes(): Nos da un true o false rápido.
indexOf(): Nos dice exactamente dónde está, o -1 si no existe.

Consigna: Checkpoint de Arrays
En esta entrega, integrarás lo aprendido sobre arrays en la estructura de proyecto que venimos desarrollando.

Criterios de Aceptación:
El código debe ser funcional y no arrojar errores en la consola.

El uso de for...of debe estar correctamente implementado para recorrer la lista.
Se debe continuar trabajando con las herramientas vistas hasta el momento (funciones, condicionales, ciclos) en un entorno de simulador, no pueden ser herramientas sueltas.
Pasos sugeridos:
Preparación de la Colección:
Crea un array con un nombre semántico asociado a tu proyecto.
Inicialízalo con al menos 5 elementos (strings o números).
Manipulación Dinámica:

Agrega uno al principio usando unshift.
Elimina el último elemento y guárdalo en una variable para mostrarlo en un mensaje: "Se ha eliminado el elemento: [nombre]".
Búsqueda y Validación:
Solicita al usuario (mediante prompt o una variable fija) el nombre de un elemento para buscar.
Usa includes para verificar si existe.
Si existe, usa indexOf para informar en qué posición (índice) se encuentra.
Actualización por Índice:
Busca un índice específico y cambia su valor por uno nuevo implementando el método splice.
Reporte Iterativo:

Dentro de la función, utiliza un bucle for...of para recorrer el array y mostrar cada elemento con un formato claro (ej: "Producto: Manzana").
